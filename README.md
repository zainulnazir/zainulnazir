## Selected Work

### NIR Vein Finder

A Raspberry Pi-based **near-infrared vein visualization system** using an NoIR camera, 850 nm illumination, and computer-vision processing to enhance superficial vein visibility in real time.

**Python · OpenCV · scikit-image · Raspberry Pi · NIR imaging · Flask**

[Repository](https://github.com/zainulnazir/vein-finder) · [Research Paper](https://pub-0951765016044c0d8d09ae3469298c27.r2.dev/research/Research%20NIR%20Vein-Finder.pdf)

### CuraLytica

A healthcare-focused AI prototype exploring **medical-image analysis and diagnostic decision support** through machine-learning workflows.

**Python · Machine Learning · Medical Imaging · Flask · React**

[Repository](https://github.com/zainulnazir/CuraLytica)

### MPVKit-Swift

A Swift Package Manager-ready macOS wrapper and packaging pipeline for **libmpv and MoltenVK**, designed to simplify integrating native media playback into Swift applications.

**Swift · macOS · SwiftUI · libmpv · MoltenVK · XCFramework · SPM**

[Repository](https://github.com/zainulnazir/MPVKit-Swift)

### Hydra

A highly concurrent HTTP stream aggregation system with caching, resilient fetching, automated extractor verification, and configurable AI-assisted extraction.

**Node.js · Redis · Docker · HTTP · Automation · AI APIs**

[Repository](https://github.com/zainulnazir/hydra)

### TheLoomReport

An automated AI publication pipeline that combines content generation, moderation, image processing, editorial review through GitHub pull requests, newsletters, and continuous deployment.

**Eleventy · Node.js · Gemini · GitHub Actions · SendGrid · CI/CD**

[Repository](https://github.com/zainulnazir/theloomreport)
